# bark-icons

Bark 通知图标的「圆形适配」版 —— iOS 会把通知图标裁成正圆，直接用 emoji PNG 会显小留白。
本仓库的图标 = 彩色圆底填满画布 + emoji 居中，圆形裁切后是完整的实心圆。

生成脚本：`make_icons.py`（需要 Pillow）。

## 引用（jsDelivr）

```
https://cdn.jsdelivr.net/gh/xmgzxmgz/bark-icons@main/<code>.png
https://testingcf.jsdelivr.net/gh/xmgzxmgz/bark-icons@main/<code>.png   # 国内推荐
```
